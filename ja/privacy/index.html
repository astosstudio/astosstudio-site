プライバシーポリシー

最終更新日：2026年11月7日

このポリシーでは、お客様が Mob Holdout: Mafia Defense をプレイしたり、このウェブサイトを訪問したり、メールを送信したりする際に、AstosStudio がどのような個人データを取り扱うのか、その理由、そして EU 一般データ保護規則（GDPR）に基づくお客様の権利について説明します。

このポリシーは Mob Holdout: Mafia Defense とこのウェブサイトに適用されます。Daily Puzzle Club、Rocket Rain、Kermis Jackpot はまだ開発中のため、リリース前にこのポリシーに追加します。

AstosStudio は、オランダ商工会議所（KvK）に登録番号 93013116 で登録されているオランダの個人事業（eenmanszaak）です。AstosStudio は、ここに記載する取り扱いのデータ管理者です。

プライバシーやお客様のデータに関するお問い合わせ：support@astosstudio.com

Mob Holdout: Mafia Defense

取り扱うデータ

  • 匿名のプレイヤーアカウント。初回起動時に、ゲームは名前、メールアドレス、電話番号のないアカウントを作成します。付与されるのはランダムなプレイヤー ID だけです。
  • ゲームの進行状況。進行状況、ランキングのスコア、ご自身で選んだプレイヤー名。他のプレイヤーはプレイヤー名とスコアを見ることができます。
  • ファミリー。ファミリーを作成または参加した場合：ファミリー名とタグ、ランク、寄付とポイント。他のプレイヤーはプレイヤー名とランクを見ることができます。
  • チャットとプライベートメッセージ。メッセージごとに：お客様のプレイヤー ID と名前（プライベートメッセージの場合は受信者の ID と名前も）、ファミリーまたは会話、ファミリー内のランク、本文（最大200文字）またはクイックメッセージやエモート、端末の言語と送信時刻。ファミリーチャットはそのファミリーのメンバーだけが、プライベートメッセージはお客様と相手のプレイヤーだけが見ることができます。
  • メッセージ設定。プライベートメッセージを送れる相手：全員、ファミリー、または誰も送れない。
  • 通報とブロック。プレイヤー、ファミリー、メッセージを通報した場合：お客様のプレイヤー ID、通報の対象、その時点の名前、理由と状況（チャットメッセージの場合は本文も）、対応状況、スタッフのメモ、時刻。プレイヤーをブロックした場合：お客様のプレイヤー ID、ブロックしたプレイヤーの ID、時刻。端末とクラウドのセーブデータには、ブロックしたプレイヤーとファミリー（ID と名前）、プライベート会話をどこまで読んだかも保存されます。
  • 利用停止。ルール違反によりアカウントを停止した場合：プレイヤー ID、理由、時刻。
  • 公正なプレイ。プレイしたゲームごとに：モード、ミッションのレベル、開始・終了時刻、スコア、ウェーブ数、撃破数、そしてスコアが当社の上限内だったかどうか。さらに、ファミリーへの寄付、陣営ポイント、ファミリー戦の攻撃回数、任務への貢献の1日ごとの合計。これらを使って、ランキングのスコアとファミリーポイントが実際に達成可能かを確認します。ゲームはお使いの携帯電話の時計ではなく、当社サーバーの時刻を使用します。
  • ゲーム統計。プレイするモード、どこまで進んだか、開いた画面、技術的なエラー。通報や翻訳をした場合は、それが行われたことと、種類と理由または言語の組み合わせのみを記録し、本文は一切記録しません。これらの統計は名前ではなく、ランダムなプレイヤー ID に紐づきます。Settings › Share anonymous gameplay data でオフにできます。
  • 購入。支払いは Apple または Google を通じて行われます。RevenueCat を通じて受け取るのは、どの購入をしたか、VIP などのサブスクリプションが有効かどうかだけです。お支払い情報を受け取ることは一切ありません。
  • 広告。任意のリワード広告は Google AdMob が提供します。EU および EEA では、ゲームはまずお客様の同意を求めます。同意がない場合はパーソナライズされていない広告が表示されますが、Google は広告の表示・測定や不正防止のために、IP アドレスや端末情報などの限られたデータを使用することがあります。iPhone では、広告のためのトラッキングを許可するかどうかを別途確認します。この設定は iPhone の 設定 › プライバシーとセキュリティ › トラッキング でいつでも変更できます。

安全なチャット

不快な言葉を含む名前やメッセージはブロックされ、電話番号、メールアドレス、リンクを含むメッセージは送信されません。スタッフは通報されたメッセージのみを確認し、ルールに違反するメッセージを非表示にしたり、アカウントを停止したりすることができます。

翻訳ボタン

他の言語で書かれたメッセージの下にある Translate をタップできます。このときに限り、お使いの端末はそのメッセージ1件の本文と2つの言語（送信者の言語または自動検出、そしてお使いの端末の言語）を、イタリアの Translated srl が提供する翻訳サービス MyMemory に直接送信します。MyMemory はお客様の IP アドレスを確認できますが、プレイヤー ID や名前を見ることはありません。翻訳結果は保存せず、ゲームを開いている間だけゲームのメモリ内に残ります。MyMemory によるリクエストの取り扱いには、Translated のプライバシーポリシーが適用されます。

このウェブサイト

このウェブサイトは Cookie も第三者のトラッカーも使用していません。フォントはこのサイト自体から配信しています。サイトは GitHub（GitHub Pages）でホストされており、GitHub はサイトの配信と保護のためにサーバーログで IP アドレスを処理します。

ページビューは Cookie を使わず、IP アドレスを保存せずに自社で集計しています。1回の閲覧ごとに保存するのは、ページ、参照元のウェブサイト（例：google.com）、ブラウザの言語、端末の種類（スマートフォン、タブレット、パソコン）、時刻のみです。これにより役立つページがわかりますが、お客様個人を特定することはできません。集計データはフランクフルトの Supabase に保存され、Supabase はサービスの提供と保護のためにリクエストログで IP アドレスを短時間処理します。集計データは13か月後に削除します。ブラウザが Do Not Track または Global Privacy Control のシグナルを送信している場合、訪問は集計しません。

どちらも法的根拠は正当な利益（第6条1項(f)）です。

メールでお問い合わせいただいた場合

メールをお送りいただいた場合、お客様をサポートするためにメールアドレス、メッセージ、添付ファイルを使用します。当社のメールはオランダの TransIP でホストされています。サポートメールはお問い合わせへの対応が終わるまで保管し、その後、繰り返し発生する問題を把握するために最長2年間保管します。法的根拠：正当な利益（第6条1項(f)）、または購入に関するお問い合わせの場合は契約の履行。

データの提供先

  • Supabase：ゲームサーバー、データベース、ウェブサイト統計。EU（フランクフルト）。処理者。
  • RevenueCat：購入とサブスクリプションの処理。米国。処理者。
  • Google（AdMob）：広告。パーソナライズ広告については、Google が独立した管理者となります。Google のプライバシーポリシーをご覧ください。
  • Apple と Google：アプリストアと支払い。それぞれが独立した管理者です。
  • Translated srl（MyMemory）：Translate をタップしたときのメッセージ翻訳。イタリア（EU）。リクエストはお使いの端末から MyMemory に直接送信されます。
  • 他のプレイヤー：プレイヤー名、スコア、ランク、ファミリーチャットのメッセージ、そしてお客様が送ったプライベートメッセージを見ることができます。
  • GitHub：このウェブサイトのホスティング。米国。処理者。
  • TransIP：メールのホスティング。オランダ。処理者。

データが米国に移転される場合は、EU-米国データプライバシーフレームワークや欧州委員会の標準契約条項などの適切な保護措置のもとで行われます。お客様のデータを販売することはありません。

データの保存期間

ゲームのデータはアカウントが存在する間保存しますが、以下は例外です。

  • チャットとプライベートメッセージ：30日間。
  • 通報：12か月間。
  • 利用停止：解除されるまで。
  • ブロック：お客様が解除するまで。
  • 公正なプレイのためのゲーム結果：35日間。
  • ファミリーの1日ごとの合計：14日間。

Settings › Delete account and data から、すべてをご自身で削除できます。これにより、アカウント、進行状況、スコア、ファミリーのデータ、メッセージ設定、ブロック、ゲーム統計、ゲーム結果、メッセージ（他のプレイヤーとの会話を含む）、そしてお客様が行った通報とお客様に関する通報が、当社のサーバーから直ちに削除されます。ファミリーのリーダーである場合、リーダーは最もランクの高いメンバーに引き継がれます。詳しくはアカウントの削除をご覧ください。

購入履歴はストアのアカウントの一部であるため、Apple または Google に残ります。サブスクリプションは App Store または Google Play の設定で解約してください。ゲームのアカウントを削除しても解約にはなりません。

お客様の権利

お客様には、ご自身のデータへのアクセス、訂正、削除を求める権利、取り扱いの制限や取り扱いへの異議（ゲーム統計を含む）を求める権利、そしてデータポータビリティの権利があります。同意に基づく取り扱いについては、いつでも同意を撤回できます。撤回は、それ以前に行われた取り扱いには影響しません。

これらの権利を行使するには、support@astosstudio.com までメールをお送りください。お客様のアカウントには名前もメールアドレスもないため、データを見つけられるよう、プレイヤー ID（Settings で確認できます）またはプレイヤー名を記載してください。1か月以内に回答します。

オランダのデータ保護機関 Autoriteit Persoonsgegevens、またはお住まいの国のデータ保護機関に苦情を申し立てることもできます。
